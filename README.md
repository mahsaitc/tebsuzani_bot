# tebsuzani_bot

ربات تلگرام برای مدیریت کانال کلینیک: انتشار فوری پست، زمان‌بندی پست با تاریخ شمسی، و مدیریت صف انتشار.

## امکانات

| دستور | کار |
|---|---|
| `/post` | انتشار فوری یک پست (متن، عکس یا ویدیو با کپشن) بعد از پیش‌نمایش و تأیید |
| `/schedule` | زمان‌بندی پست برای تاریخ و ساعت مشخص (شمسی یا میلادی، به وقت تهران) |
| `/queue` | فهرست پست‌های زمان‌بندی‌شده با شماره و زمان |
| `/cancel 3` | حذف پست شماره ۳ از صف |
| `/cancel` | لغو کاری که در حال انجامش هستید |
| `/id` | نمایش شناسه عددی شما (برای تنظیم `ADMIN_IDS`) |

- فقط مدیرانی که شناسه‌شان در `ADMIN_IDS` است می‌توانند پست بگذارند.
- قالب‌بندی متن (بولد، ایتالیک، لینک و …) حفظ می‌شود.
- پست‌های زمان‌بندی‌شده در SQLite ذخیره می‌شوند، پس با ری‌استارت ربات از بین نمی‌روند.
- بعد از انتشار هر پست زمان‌بندی‌شده (یا خطا در انتشار)، به مدیری که آن را ساخته پیام داده می‌شود.

قالب‌های قابل قبول برای زمان (اعداد فارسی هم پذیرفته می‌شوند):

```
1405/07/28 18:30    تاریخ شمسی
2026-10-20 18:30    تاریخ میلادی
18:30               امروز، یا فردا اگر این ساعت گذشته باشد
```

## راه‌اندازی

### ۱. ساخت ربات در BotFather

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید و `/newbot` را بفرستید.
2. یک نام و یک یوزرنیم (که به `bot` ختم شود) انتخاب کنید.
3. توکنی که BotFather می‌دهد را نگه دارید؛ این همان `BOT_TOKEN` است. آن را با کسی به اشتراک نگذارید.

### ۲. ادمین کردن ربات در کانال

1. وارد تنظیمات کانال شوید: **Administrators ← Add Admin**.
2. یوزرنیم ربات را جستجو و اضافه کنید.
3. دسترسی **Post Messages** را فعال بگذارید (بقیه دسترسی‌ها لازم نیست).

برای `CHANNEL_ID`:
- کانال عمومی: یوزرنیم کانال، مثلاً `@my_channel`
- کانال خصوصی: شناسه عددی که با `-100` شروع می‌شود. یک پست از کانال را برای [@userinfobot](https://t.me/userinfobot) یا ربات مشابه فوروارد کنید تا شناسه را ببینید.

### ۳. پیدا کردن شناسه عددی مدیران

ربات را اجرا کنید و `/id` را برایش بفرستید، یا از [@userinfobot](https://t.me/userinfobot) استفاده کنید. چند شناسه را با کاما جدا کنید: `ADMIN_IDS=111,222`.

### ۴. تنظیمات

فایل `.env.example` را به `.env` کپی کنید و مقادیر را پر کنید:

```bash
cp .env.example .env
```

| متغیر | ضروری | توضیح |
|---|---|---|
| `BOT_TOKEN` | بله | توکن BotFather |
| `CHANNEL_ID` | بله | `@username` یا شناسه عددی کانال |
| `ADMIN_IDS` | بله | شناسه‌های عددی مدیران، جدا با کاما |
| `TIMEZONE` | خیر | پیش‌فرض `Asia/Tehran` |
| `DB_PATH` | خیر | پیش‌فرض `data/bot.db` |

### ۵. اجرا روی کامپیوتر (Python 3.10 یا بالاتر)

```bash
python -m venv .venv
source .venv/bin/activate        # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot.main
```

### ۶. اجرا با Docker (پیشنهادی برای سرور)

```bash
docker compose up -d --build
docker compose logs -f           # دیدن لاگ‌ها
```

پایگاه داده در پوشه `data/` کنار پروژه ذخیره می‌شود و با به‌روزرسانی کانتینر پاک نمی‌شود.

> نکته: اگر سرور در ایران است، دسترسی به `api.telegram.org` ممکن است محدود باشد؛ سرور خارج از ایران گزینه مطمئن‌تری است.

## اجرای تست‌ها

```bash
pip install pytest
python -m pytest
```

## ساختار پروژه

```
bot/
  main.py       نقطه شروع
  config.py     خواندن تنظیمات از متغیرهای محیطی / .env
  db.py         ذخیره پست‌ها در SQLite
  handlers.py   دستورها، گفتگوی ساخت پست و زمان‌بند انتشار
  timeutil.py   تبدیل تاریخ شمسی/میلادی
tests/          تست‌ها
```
